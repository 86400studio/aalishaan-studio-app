# Session continuity

Before reviewing or revising this website, read `PAGE-TRACKER.md`, especially Resume here and the latest session log. It is the persistent source for page revision status and user sign-offs.

Update the tracker after each review/revision session with completed work, relevant checks, outstanding feedback and the next action. Follow the user's requested page order. Only mark a page SIGNED OFF when the user explicitly approves it; record the revision identifier, date and approval scope. Existing prototypes and passing tests do not constitute sign-off.

Use `README.md`, `docs/PAGE-AUDIT.md` and `docs/IMAGE-AUDIT.md` for consolidation context. Preserve the current Home design until the user requests specific revisions. This instruction does not prevent authorized fixes or require approval for routine work.
