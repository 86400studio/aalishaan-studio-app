## Review boundary

Use fictional data only. A1 saves its own demo state in a dedicated browser-storage key and can reset it. It does not read or change the public cart, catalogue sources or W1. Browser role checks demonstrate the intended experience; they are not authentication or a security boundary. Provider outcomes are chosen simulations. Documents are marked samples and use no invented tax treatment. Business-rule values are visibly unapproved examples.

Open `admin/index.html`. Start with Today, follow AS-1001 from payment to delivery, then use Review journeys for US01–US23. Each journey loads a fresh scenario after confirmation, so exceptions are reproducible. Review each menu and use Settings → Readiness for scope coverage and remaining live evidence.

Verification results and owner feedback are recorded at completion below and in PAGE-TRACKER.md. Passing prototype checks does not mark Admin signed off.
